Pregunta 01

¿Qué es el DNS y para qué sirve?

El DNS (Domain Name System o Sistema de Nombres de Dominio) actúa como la "agenda telefónica" o el directorio oficial de Internet. Su función principal es traducir nombres de dominio legibles por humanos (como wikipedia.org) a direcciones IP numéricas (como 198.35.26.96) que las computadoras utilizan para comunicarse entre sí en la red.

💡 Clave: Traducción de nombres a IPs
Pregunta 02

¿Por qué usamos nombres y no IPs?

Los seres humanos somos excelentes recordando palabras, nombres y patrones lingüísticos, pero terribles memorizando secuencias numéricas largas (¡imagínate recordar una IP diferente para cada sitio que visitas!). Las direcciones IP además pueden cambiar con el tiempo o variar según el servidor, mientras que el nombre de dominio permanece constante.

💡 Clave: Usabilidad y memorización humana
Pregunta 03

¿Cuál es el recorrido para encontrar una IP?

Cuando buscas una web, la petición realiza un recorrido jerárquico:
1. Caché Local: Navegador y Sistema Operativo.
2. ISP / Resolver recursivo: Preguntas a tu proveedor de internet.
3. Servidores Raíz (Root): Dirigen al servidor TLD correcto.
4. Servidor TLD (.org, .com): Apunta al servidor autoritativo.
5. Servidor Autoritativo: Tiene el registro final con la IP exacta.

💡 Clave: Búsqueda jerárquica en cascada
Pregunta 04

¿Qué ocurre al obtener la IP?

Una vez obtenida la dirección IP, ocurren tres fases clave en milisegundos:
- Conexión TCP / TLS: Se establece un canal seguro de comunicación con el servidor (Handshake).
- Petición HTTP/HTTPS: Tu navegador pide los archivos (HTML, CSS, JS).
- Renderizado: El navegador procesa el código recibido y dibuja la interfaz gráfica en tu pantalla.

💡 Clave: Conexión, transferencia y render
Pregunta 05

¿Qué es la Caché DNS y el TTL?

Para evitar hacer todo el recorrido jerárquico cada vez que haces clic, las respuestas DNS se guardan temporalmente en la Caché DNS.
El TTL (Time To Live o Tiempo de Vida) es un valor en segundos que indica cuánto tiempo debe almacenar el sistema esa IP antes de volver a consultar al servidor oficial.

💡 Clave: Velocidad y caducidad de datos
Pregunta 06

¿Una web puede tener una o varias IP?

¡Sí, puede tener varias! Gracias a tecnologías avanzadas:
- Round Robin: Distribuye peticiones alternando entre varias IPs de servidores.
- Anycast y CDNs: Replicar la misma IP en servidores de todo el mundo para que te atienda el nodo geográficamente más cercano, reduciendo la latencia al mínimo.

💡 Clave: Escalabilidad y balanceo de carga
